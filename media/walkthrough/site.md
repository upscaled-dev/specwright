# Site URL and region

Specwright talks to **Jira Xray Cloud**. Point it at your Atlassian site and pick the API region that matches your account.

- **Site URL** — your Atlassian host, e.g. `your-team.atlassian.net`. A full URL or trailing slash is fine; Specwright normalizes it.
- **Region** — `global`, `us`, `eu`, or `au`. The same region host is used for authentication, reads, and publishing.

Use **Open Xray Setup** to enter these in the setup panel.
