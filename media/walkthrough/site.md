# Site URL and region

Specwright talks to **Jira Xray Cloud**. Point it at your Atlassian site and pick the API region that matches your account.

- **Site host**: your Atlassian host, for example `acme.atlassian.net`. A full URL or trailing slash is fine; Specwright normalizes it.
- **API region**: **Global**, **US**, **EU**, or **AU**. The same region host is used for authentication, reads, and publishing.

Use **Open Xray Setup** to enter these in the setup panel.
